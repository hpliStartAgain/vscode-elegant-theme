# Elegant Theme Collection

28 color themes (14 dark, 14 light) for VS Code, generated from the same palettes as the Elegant Theme plugin for JetBrains IDEs, so the two editors can match exactly.

- Dark themes sit on a near-black base with a faint hue tint; light themes sit on pure white (Linen, Ink Light and Claude Light on a faint cream).
- Every syntax token carries a color — no white or neutral tokens.
- Every syntax color meets WCAG 4.5:1 against the editor background; body text meets 7:1.
- Semantic highlighting is enabled, with terminal, git decoration, diff and bracket-pair colors tuned per theme.

## Dark

Elegant Dark, Elegant Islands Dark, Elegant Midnight, Elegant Aurora, Elegant Sakura Night, Elegant Ocean Deep, Elegant Neon Candy, Elegant Forest Night, Elegant Sunset Ember, Elegant Lavender Dusk, Elegant Mint Noir, Elegant Graphite Pop, Elegant Claude Dark, Elegant Firefox Dark.

## Light

Elegant Islands Light, Elegant Ink Light, Elegant Snow, Elegant Sakura, Elegant Mint, Elegant Lavender, Elegant Peach, Elegant Sky, Elegant Lemon, Elegant Coral Reef, Elegant Candy Pop, Elegant Linen, Elegant Claude Light, Elegant Firefox Light.

## Usage

Preferences → Color Theme (`Ctrl+K Ctrl+T` / `Cmd+K Cmd+T`) and pick any theme starting with "Elegant".

Source, palettes and the JetBrains plugin: https://github.com/hpliStartAgain/vscode-elegant-theme
